# Validated `k=6` physical example

This directory contains one explicit validated simple-fold realization for `k=6`, `2×12`, canonical pleat word `MVMVMV`, in the ideal zero-thickness model.

It is a **physical intuition/example track**, not the general theorem. The paper classifies final labelled layer orders; this trajectory certifies one explicit physical realization.

Assets:

- `poster.svg` — opening frame / static fallback;
- `final.mp4`, `final.webm` — polished validated motion;
- `trajectory.json` — stored trajectory;
- `validation.json` — validation record;
- `physical_case.fold` — FOLD representation.
