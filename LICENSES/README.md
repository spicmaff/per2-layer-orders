# License scopes — author decision required

No license choice is asserted here without rights-holder approval.

Suggested scopes for review:

- `src/`, `tools/`, tests, reproduction wrappers, web source: permissive software license such as BSD-3-Clause or MIT;
- machine-readable reference data: CC0-1.0 or CC BY 4.0 if intentionally approved;
- new repository documentation/explanatory figures: CC BY 4.0 if approved;
- manuscript, supplements, and publication figures/source: follow the actual paper/preprint/publisher arrangement.

Until a scope is approved, do not infer reuse rights from the presence of the file in this implementation package.
