# Map & Layer-Order Explorer

## Scope

The Explorer presents a deliberately bounded set of canonical scenes without moving scientific decisions into the browser.

### `MVMMMM` LIFO mode

- `k=3`, canonical `MVMMMM`;
- upper and lower pivots `a,b ∈ {1,…,5}`;
- all 25 pivot pairs exported in Python;
- coordinated physical map, row normal forms, global layer-order prefix and LIFO trace;
- `Previous / Next / Reset`, Basic/Proof annotations, face/MV toggles, literal/exploded layer presentation, optional schematic motion.

### `MMMMVV` prepared-scene mode

Fixed `k=4` with exactly three exported scenes:

- diagonal success `(3,3)`;
- boundary success `(1,4)`;
- interior off-diagonal directed-cycle obstruction `(2,3)`.

The two compatible scenes display their exact theorem construction orders. The obstruction scene reveals the already-exported four inequalities step by step and never fabricates an exact state.

## Trust boundary

The browser never compares `B_R` values, tests diagonal/boundary conditions, generates row forms, constructs exact states, generates a cycle witness, validates a state, or chooses the next LIFO event. It renders versioned records generated by `per2.export.site_data`.

All scenes are explicitly combinatorial. No Explorer transition claims a physical folding path.

## Scientific sentinels

### `MVMMMM` success `(2,3)`

Exact 12-event order:

`A3 A5 A6 A4 B4 B6 B5 A1 A2 B2 B1 B3`.

### `MVMMMM` failure `(2,4)`

Stops before `B3`:

- requested closer `H3`;
- stack `H3 H5 H6` bottom-to-top;
- blocking top `H6`;
- reason `BURIED_CLOSER`.

### `MMMMVV` prepared scenes

- diagonal: `(3,3)`, exact semantic-valid construction;
- boundary: `(1,4)`, exact semantic-valid construction;
- obstruction: `(2,3)`, exported cycle `A4 ≺ A1 ≺ B1 ≺ B4 ≺ A4`, with the fourth relation marked as cycle-closing.

## Shareable prepared routes

- `?mechanism=mvmmmm&a=2&b=3`
- `?mechanism=mvmmmm&a=2&b=4`
- `?mechanism=mmmmvv&scene=diagonal`
- `?mechanism=mmmmvv&scene=boundary`
- `?mechanism=mmmmvv&scene=obstruction&step=4`

URL state selects an exported scene or pivot record; it does not encode derived scientific facts.

## Deliberate scope boundary

Arbitrary `k=2..12`, free-form period words, symmetry-generalized scene selection, and full state-set browsing are intentionally unsupported in this release. The public Explorer is an explanatory interface over exported canonical records, not an alternate mathematical engine.
